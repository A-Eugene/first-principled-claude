---
name: first-principled
description: >-
  Reasoning discipline. Load it BEFORE forming an approach to a design, an
  analysis, a diagnosis whose cause is not yet known, a choice between options,
  a verdict question ("is X safe", "should we ship this", "which is better"),
  or any change that cannot be undone or takes a day or more to undo. Load it
  before asserting something you have not verified. In a project with a locked
  spec, like a submitted proposal, load it before any change, even one line.
  Skip it when the correct result can be stated before the work starts: a
  rename, a format change, a lookup a file or a tool answers, a change the user
  dictated word for word. Governs naming an alternative before committing,
  concluding last, verifying against tools, knowing which claims are checked,
  and treating choices made without evidence as provisional.
---
